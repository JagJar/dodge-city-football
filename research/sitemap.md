# Historical route restoration

Machine-readable inventories are generated by `scripts/build.py`:

- `restoration-pages.json`: page title, recovery status, source, and output file.
- `legacy-routes.json`: canonical paths, aliases, article IDs and player IDs.

| Historical URL | Restored behavior |
| --- | --- |
| `/`, `/index.php`, `/index.html` | Canonical homepage at `/`; old entry points redirect once. |
| `/team/roster.html`, `/roster.html` | Complete 24-entry captured roster at the original team path. |
| `/team/roster/<id>-<name>.html` | Individual record reconstructed from the preserved roster fields. |
| `/team/staff-coaches.html` | Recovered staff/coaches text and portraits. |
| `/news-hm/726-731-*.html` | Individual articles: four releases, one excerpt, one attributed summary. |
| `/news/headline-news.html`, `/news-hm.html` | Redirect to `/news.html`. |
| `/schedule.html`, `/schedules.html` | Recorded 2017 schedule; legacy spelling redirects. |
| `/schedule/boxscore/<id>.html` | Known game result plus an explicit missing-statistics note. |
| `/component/gridiron/team/*` | Original team URL with its June 2 standings record. |
| `/arena/seating-chart.html` | Full recovered seating image; missing PDF explained. |
| `/tickets/ticket-pricing.html` | Recovered original pricing artwork with historical context. |
| `/tickets/tickets-pricing.html`, `/tickets/single-season-ticket-pricing.html` | Redirect to the recovered pricing page. |
| `/images/league/flyers/dodge-seating-chart.pdf` | Redirect to the seating page's missing-PDF explanation and JPEG. |
| `/images/league/pdfs/DodgeCitySeasonTicketForm.pdf` | Redirect to the original-form recovery note. |
| `/contac.html` | Redirect to historical contact information. |
| `/?option=com_content&view=article&id=<known-id>` | Specific known article; routing parameters removed, ordinary tracking parameters preserved. |
| `/?option=com_sobipro&sid=<known-id>` | Specific known roster record. |
| `/index.php/<known-path>` | Canonical known page or alias target. |
| `/?format=feed&type=rss` | Historical feed at `/feed.xml`. |
| Unknown IDs, unknown pages, unrelated parked-domain PDFs | Genuine 404 with working root-relative navigation. |

All 48 path destinations linked from the preserved homepage (including `/`) have a
local page or explicit alias. Source dates and incomplete content are described
in `provenance.md` and on the public archive pages. Incomplete records are
excluded from the sitemap and marked `noindex,follow`.
